# For HR and recruiters

Hiring lives and dies on warm relationships maintained over time. This
system turns a recruiter's network from a spreadsheet of names into a
watched pipeline with evidence.

## What you get

- **Talent pools you can query.** "Which backend engineers at Proceedit
  did I speak with last quarter?" — organization (exact-match), role,
  tags, plus interaction evidence (type + contacted-since) combine in
  one filter, in the UI or by asking Copilot. Every answer cites its
  members; counts are totals, never capped subsets.
- **Outreach at scale without spam.** Build a batch from signals
  (neglected candidates, post-interview follow-ups, upcoming start
  dates, company members), review per-person reasons, pick the channel
  per person, and approve grounded drafts one by one. Approval never
  sends — you send, then log the real conversation.
- **Cadence that fits hiring cycles.** Per-candidate rhythms ("stay in
  touch every 14 days during the search"), intentional-contact flags
  for key hires, suggestion opt-outs for placed candidates, reminders
  that never fake contact.
- **Meeting discipline.** Interview debriefs go through transcript →
  extract → map → review → confirm, becoming searchable memory with
  provenance instead of lost notes.

## Suggested workflow

1. Import or log every candidate touch (calls, emails, interviews).
2. Tag pipelines (`hiring`, `management`, stage tags) and set
   organizations/roles correctly — filters and the network graph run
   on these.
3. Weekly: open the attention queue, work the top rows, log outcomes.
4. Monthly: digest + outreach batch for dormant-but-valuable contacts.

## Honest boundaries

Scores rank *your contact history*, not candidate quality. The system
never evaluates people — only the record of your relationship with
them. Keep interview evaluation in your ATS; keep the relationship
here.
